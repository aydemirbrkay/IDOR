⚔ Saldırı Laboratuvarı — IDOR'u Canlı Dene

URL'deki fatura numarasını değiştirerek başkasının verisine erişmeyi dene. Hiç bilmiyorsan aşağıdaki adımları sırayla takip et.

Admin Paneli →
?

Burada ne yapıyoruz?

Bu sayfa bir IDOR (Insecure Direct Object Reference) zafiyetini canlı olarak deneme alanıdır. Şu an {{ user.name }} olarak giriş yaptın (kullanıcı ID'n: #{{ user.id }}). Senin faturaların sistemde {{ my_ids|join(', ') }} numaralı faturalar. Aşağıdaki butonlardan başkasının fatura numarasına tıklayıp, sunucunun sana o veriyi yetkin olmadığı halde verip vermediğini göreceğiz.

Hedef: Sağ üstte mod rozeti VULNERABLE iken başkasının faturasını görebilmek = saldırı başarılı. Sonra Admin Paneli'nden mod'u SECURE yapıp aynı saldırının nasıl engellendiğini göreceğiz.

  1. 1

    Hedef seç — başkasının fatura numarasına tıkla

    Aşağıda sistemdeki tüm fatura ID'leri var. Senin olanlar SENİN etiketli. SENİN olmayan bir numaraya tıkla — örneğin {% if other_example_id %}#{{ other_example_id }}{% else %}#2001{% endif %}. Gerçek hayatta saldırgan bu numarayı tahmin eder veya log'lardan, URL'lerden bulur.

    {% for inv_id in all_ids %} {% set mine = inv_id in my_ids %} {% endfor %}
  2. 2

    Tarayıcının ne yaptığını izle — URL ve istek

    "İstek Gönder" butonu, tarayıcına şu adrese gizli bir istek gönderir:

    {{ '{' }}origin{{ '}' }}/api/invoice/2001
    ↑ saldırının yapıldığı yer — sadece bu sayı değişir
    Aynı isteği terminalden de çalıştırabilirsin (önce ./run.sh ile sunucuyu çalışır tut): curl -b cookies.txt http://localhost:5000/api/invoice/2001 Not: -b cookies.txt oturum çerezini taşır. Tarayıcıda zaten otomatik gönderilir.
  3. 3

    Sunucu yanıtını oku

    Sunucu Yanıtı

    henüz istek gönderilmedi
    Yukarıdaki bir numaraya tıkla — buraya gelen yanıt anında düşecek.
  4. 4

    Sonucu yorumla

    ⚠ IDOR başarıyla sömürüldü Sunucu sana ait olmayan bir faturayı verdi. Mod VULNERABLE demektir.
    🛡 Erişim engellendi (HTTP 404) Sunucu sahiplik kontrolü yaptı ve veriyi vermedi. Mod SECURE demektir.
    ✓ Meşru erişim Bu fatura zaten senin (veya admin'sin). Saldırı sayılmaz.
  5. 5

    Şimdi SECURE moda geç — aynı saldırı engellenmeli

    Admin Paneli'ne git → Modu Değiştir'e bas → bu sayfaya geri dön. Aynı numaraya tıkladığında bu kez HTTP 404 ve "Erişim engellendi" görmelisin. Aradaki tek fark: tek satırlık check_object_ownership kontrolü.

    Admin Paneli'ne Git →
  6. 6

    Logları gör — saldırgan iz bırakır

    Her saldırı ve her engelleme Admin Paneli'ndeki canlı log akışına düşer. VULNERABLE modda [IDOR EXPLOIT] satırlarını, SECURE modda YETKİSİZ ERİŞİM GİRİŞİMİ satırlarını göreceksin. Sunum sırasında bu farkı yan yana göstermek çok etkilidir.
